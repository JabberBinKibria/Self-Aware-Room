## 1. Overview and Purpose

This document specifies recommended hardware architectures tailored for the downstream computational, deep learning, multimodal representation, and real-time inference layers of the Self-Aware Room (SAR).

As defined in the SAR Computational Pipeline specification, sensor telemetry acquired at L0/L1 feeds into higher-level spatial, acoustic, visual, and cognitive processing tiers. These proposals provide clear hardware scaling options ranging from room-embedded edge inference to massive local foundational model training.

## 2. Configuration Breakdown

### Configuration 1: Limitless Budget Ultimate AI Workstation
*Designed for enterprise AI research, multi-billion parameter model fine-tuning, and massive parallel workloads without compute bottlenecks.*

#### Core Components
- **GPUs:** 4x NVIDIA RTX 6000 Ada Generation (192 GB total VRAM)
- **Processor:** AMD Ryzen Threadripper PRO 7995WX (96 Cores, 192 Threads)
- **Memory:** 1 TB DDR5 ECC Registered RAM (8-Channel)
- **Storage:** 8 TB NVMe PCIe 5.0 SSD (Primary OS/Cache) + 30 TB NVMe PCIe 4.0 SSD (Dataset Storage Array)
- **Motherboard:** Enterprise WRX90 Chipset Motherboard (7x PCIe Gen 5 x16 slots)
- **Power Supply:** Dual 1600W (3200W total redundant power system)
- **Cooling:** Custom Liquid Cooling Loop for GPUs and CPU

#### Key Benefits
- **Uncompromised VRAM capacity:** 192 GB of total high-speed VRAM allows local loading and fine-tuning of massive LLMs (e.g., Llama-3-70B) in FP16/BF16 precision without aggressive quantization.
- **Extreme parallel compute capability:** 96 CPU cores allow lightning-fast data preprocessing, tokenization, and pipeline execution alongside heavy GPU workloads.
- **Massive memory bandwidth:** 8-channel DDR5 ECC memory ensures fast data movement between RAM and VRAM, preventing CPU-bound bottlenecks during large dataset ingestion.
- **Enterprise reliability:** ECC memory support and dual redundant power supplies ensure stability during long, multi-day training runs.

---

### Configuration 2: $20,000 Dual-Ada Professional Workstation
*A balanced, highly cost-effective workstation designed for mid-sized AI labs, startup R&D, and independent research teams requiring high GPU memory density.*

#### Core Components
- **GPUs:** 2x NVIDIA RTX 6000 Ada Generation (96 GB total VRAM)
- **Processor:** AMD Ryzen Threadripper 7960X (24 Cores, 48 Threads)
- **Memory:** 256 GB DDR5 ECC Registered RAM (4-Channel)
- **Storage:** 4 TB NVMe PCIe 5.0 SSD (OS & Working Directory) + 8 TB NVMe PCIe 4.0 SSD (Data Storage)
- **Motherboard:** TRX50 Chipset Motherboard
- **Power Supply:** 1600W Titanium Certified PSU
- **Cooling:** High-Performance Dual-Tower Air or Closed-Loop AIO Liquid Cooling

#### Key Benefits
- **High-density GPU memory:** 96 GB total VRAM accommodates multi-GPU tensor parallelism, fine-tuning medium-to-large LLMs, and high-batch computer vision models.
- **Optimized cost-to-performance ratio:** Delivers top-tier workstation performance at a manageable capital expense for growing teams and specialized projects.
- **Expansion capability:** The Threadripper TRX50 platform provides sufficient PCIe lanes to add additional storage controller cards or higher-speed network interfaces (e.g., 100GbE InfiniBand/Ethernet) in the future.
- **Manageable power and thermal envelope:** Fits comfortably in standard office/lab power environments without needing dedicated server-rack cooling infrastructure.

---

### Configuration 3: Mac Studio Inference Cluster
*A scalable, energy-efficient localized compute cluster tailored for ultra-high-capacity LLM inference, edge deployment, and complete data privacy.*

#### Core Components
- **Compute Nodes:** 4x Apple Mac Studio (M-series Ultra processors)
- **Memory:** Up to 512 GB+ Unified Memory across the cluster
- **Interconnect:** High-speed Thunderbolt mesh / 10Gb Ethernet networking
- **Storage:** Fast internal unified SSD storage for rapid model weight loading

#### Key Benefits
- **Massive Unified Memory:** Access to vast amounts of fast memory per node to easily load and serve giant models locally without discrete GPU VRAM restrictions.
- **Extremely Low Power Consumption:** Highly efficient silent operation and low thermal output, perfect for continuous local deployments.
- **High Data Sovereignty:** Guarantees 100% on-premises execution without reliance on third-party cloud infrastructure.
- **SAR Alignment:** Highly suited for the Self-Aware Room (SAR) project to run a custom local LLM with complete data privacy and seamless edge-hardware integration.

---

### Configuration 4: Embedded Multimodal Edge AI Node (Lab Recommendation)
*A dedicated in-room, low-power edge compute node designed for real-time sensor fusion, computer vision, and spatial acoustic inference directly within the SAR physical envelope.*

#### Core Components
- **Compute Engine:** NVIDIA Jetson AGX Orin Developer Kit (64 GB Unified Memory)
- **AI Performance:** Up to 275 TOPS (INT8) sparse compute
- **GPU Architecture:** 2048-core NVIDIA Ampere architecture GPU with 64 Tensor Cores
- **CPU:** 12-core Arm Cortex-A78AE v8.2 64-bit CPU
- **Memory Bandwidth:** 2048-bit bus with 204.8 GB/s bandwidth
- **Storage:** 64 GB eMMC 5.1 + 2 TB M.2 NVMe SSD expansion
- **Power Envelope:** Configurable 15W – 60W operational draw

#### Key Benefits
- **True In-Room Edge Integration:** Operates completely silent at 15–60W, allowing persistent physical mounting inside the room enclosure alongside sensor clusters.
- **Unified Multimodal Sensor Fusion:** Direct hardware interface capability (Gigabit Ethernet, CSI camera inputs, USB 3.2, PCIe) to ingest BME680 arrays, depth cameras, and spatial microphone arrays simultaneously with sub-10ms inference latency.
- **Compact & Cost-Effective:** Delivers localized workstation-class tensor compute (~$2,000) dedicated to real-time perception rather than competing for shared cluster compute.
- **ROS 2 & TensorRT Native:** Out-of-the-box hardware acceleration for robotics middleware, real-time spatial SLAM, and room state estimation.
